# Finance_tracker
A simple tool to track personal income and expenses, helping you manage your finances efficiently.

**Features**

Add transactions (income or expense)

Edit existing transactions

Delete transactions

View all transactions

Show total income, expenses, and net balance

Supports multiple currencies with conversion to GBP

Exchange rate API integration

\
\
\
**Technologies Used**

Python 3

CSV module (for data storage)

OS module (for file handling)

\
\
**How to Run**

Clone the repository

Navigate to the project folder

Run the app:
main.py

(Note: Transactions are automatically saved to the CSV)
